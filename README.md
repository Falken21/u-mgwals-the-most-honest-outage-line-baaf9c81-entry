## The entry

> Status: Everything is down. Cause: we deployed on a Friday. ETA: unknown, because the engineer who can fix it is the same one who caused it.

(140 characters, single line.)

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
Python 3 standard library only; nothing to install.
